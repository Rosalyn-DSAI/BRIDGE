# BRIDGE email

BRIDGE supports two email modes:

- `MAIL_MODE=local` — development inbox inside the local app; no real email is sent.
- `MAIL_MODE=gmail` — real sign-in and reminder emails through Gmail SMTP.

For Gmail configuration, use [GMAIL_SETUP.md](GMAIL_SETUP.md).

For the full application setup, use [QUICKSTART.md](QUICKSTART.md).
